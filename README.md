# 大鉄道共和国 - 装甲列車タワーディフェンス

キャンバスで動く、HTML/CSS/JavaScript分割構成のブラウザゲームです。

**Play:** https://great-railway-republic.pages.dev/

## 概要

装甲列車「アイン・ソフ・オウル」を指揮し、襲来する敵部隊を迎撃するタワーディフェンスです。
4両の車両に、上部・側面それぞれへ兵装を搭載し、セフィラ（駅員）を編成してステージを進みます。ボスを撃破して鹵獲超兵器を集め、
転生（プレステージ）でセフィロトの樹を強化しながら周回します。

## 主な要素

- 4両編成 / 各車両の上部・側面スロット（計7スロット）と兵装・セフィラのシナジー
- 戦術（常時パッシブ）とレベル強化
- 鹵獲超兵器（護衛機）の編成・育成
- セフィロトの樹（恒久強化）
- ボス固有特性・大ボス必殺技
- ステージ周回報酬・転生
- チケットガチャ（ノーマル／レア／製造元ピックアップ）
- 武装レアリティ（Common〜Mythic）・＋値・マージ・強化素材による上限突破
- 鹵獲機強化モジュール
- 同型鹵獲機10体で1凸（Lv+1）
- レールガンの自動レアリティ昇格（転生回数＋クリフォト中枢制圧）
- モバイル対応レイアウト

> レールガン系武装はガチャ・＋値・マージ・上限突破の対象外です。レアリティのみ、転生回数とクリフォト中枢制圧に応じて自動昇格します（最大Legendary）。

## 遊び方

1. **戦況・操作** から出撃し、敵部隊を迎撃します。
2. **部隊編成** で各車両の兵装とセフィラを設定します。得意兵装が一致するとシナジーが発動します。
3. **研究開発** で兵装・装甲を強化します。
4. **戦術** で4種の戦術から1つを選び、常時効果を有効にします。
5. ボスを撃破すると鹵獲超兵器を入手できます。**鹵獲** タブで編成・強化・売却ができます。
6. ステージクリアでガチャチケットを獲得します。**ガチャ** タブで強化素材・鹵獲機強化モジュール・武装を入手できます。
7. **武装** タブでガチャ産武装のレアリティ・＋値・Lvを管理し、同条件3個のマージと強化素材による上限突破を行います。
8. 鹵獲超兵器は同型を10体集めるごとに1凸（Lv+1）します。1体ごとのLvアップは行いません。ゴールドでの強化は従来どおり可能です。
9. レールガンは転生回数とクリフォト中枢の制圧状況に応じて、自動的にレアリティが昇格します。
10. 進行が壁に当たったら、同じステージを周回して資金を稼ぎ、強化して突破します。
11. 条件を満たすと **プレステージ** で転生し、セフィロトの樹を永続強化できます。

### 操作

- **AUTO**: 自動進軍
- **周回**: 同じステージを繰り返す
- **速度**: ゲーム速度の切り替え
- セーブは自動で `localStorage` に保存されます。設定（⚙️）から初期化できます。

## 構成

- `game-deploy-v2/index.html` — HTML
- `game-deploy-v2/css/styles.css` — カスタムCSS
- `game-deploy-v2/css/tailwind.css` — Tailwindの生成CSS
- `game-deploy-v2/js/data.js` — ゲームデータ（兵装・敵・勢力・セフィロト等）
- `game-deploy-v2/js/state.js` — ゲーム状態・戦術定義
- `game-deploy-v2/js/gacha.js` — ガチャ・レアリティ・マージ・上限突破・鹵獲モジュール
- `game-deploy-v2/js/game.js` — 戦闘・UI・セーブ/ロード
- Tailwind CSS（CDN）と Canvas 2D を使用

## 開発・デプロイ

ローカルで動かす場合:

```powershell
python -m http.server 8765 --directory game-deploy-v2
```

`http://localhost:8765/` を開いてください。

本番は Cloudflare Pages の `great-railway-republic` プロジェクトで配信しています。

## 注意

- セーブデータはブラウザの `localStorage` に保存されます。ブラウザや端末を変えると引き継がれません。
- 本リポジトリは個人制作のゲームです。
