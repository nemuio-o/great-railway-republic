# 大鉄道共和国 - 装甲列車タワーディフェンス

キャンバスで動く、1ファイル構成のブラウザゲームです。

**Play:** https://great-railway-republic.pages.dev/

## 概要

装甲列車「アイン・ソフ・オウル」を指揮し、襲来する敵部隊を迎撃するタワーディフェンスです。
10両の車両に兵装とセフィラ（駅員）を編成し、ステージを進みます。ボスを撃破して鹵獲超兵器を集め、
転生（プレステージ）でセフィロトの樹を強化しながら周回します。

## 主な要素

- 10両編成 / 兵装とセフィラのシナジー
- 戦術（常時パッシブ）とレベル強化
- 鹵獲超兵器（護衛機）の編成・育成
- セフィロトの樹（恒久強化）
- ボス固有特性・大ボス必殺技
- ステージ周回報酬・転生
- モバイル対応レイアウト

## 遊び方

1. **戦況・操作** から出撃し、敵部隊を迎撃します。
2. **部隊編成** で各車両の兵装とセフィラを設定します。得意兵装が一致するとシナジーが発動します。
3. **研究開発** で兵装・装甲を強化します。
4. **戦術** で4種の戦術から1つを選び、常時効果を有効にします。
5. ボスを撃破すると鹵獲超兵器を入手できます。**鹵獲** タブで編成・強化・売却ができます。
6. 進行が壁に当たったら、同じステージを周回して資金を稼ぎ、強化して突破します。
7. 条件を満たすと **プレステージ** で転生し、セフィロトの樹を永続強化できます。

### 操作

- **AUTO**: 自動進軍
- **周回**: 同じステージを繰り返す
- **速度**: ゲーム速度の切り替え
- セーブは自動で `localStorage` に保存されます。設定（⚙️）から初期化できます。

## 構成

- `game-deploy-v2/index.html` — HTML
- `game-deploy-v2/css/styles.css` — カスタムCSS
- `game-deploy-v2/css/tailwind.css` — Tailwindの生成CSS
- `game-deploy-v2/js/data.js` — ゲームデータ（兵装・敵・勢力・セフィロト等）
- `game-deploy-v2/js/state.js` — ゲーム状態・戦術定義
- `game-deploy-v2/js/game.js` — 戦闘・UI・セーブ/ロード
- Tailwind CSS（CDN）と Canvas 2D を使用

## 開発・デプロイ

ローカルで動かす場合:

```powershell
python -m http.server 8765 --directory game-deploy-v2
```

`http://localhost:8765/` を開いてください。

本番は Cloudflare Pages の `great-railway-republic` プロジェクトで配信しています。

## 注意

- セーブデータはブラウザの `localStorage` に保存されます。ブラウザや端末を変えると引き継がれません。
- 本リポジトリは個人制作のゲームです。
